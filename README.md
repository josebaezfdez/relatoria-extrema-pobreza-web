# Sitio web de la Relatoría Especial

Sitio en español, inglés y francés desarrollado con Astro sobre el mandato de la Relatora Especial de las Naciones Unidas sobre la extrema pobreza y los derechos humanos.

## Desarrollo

```sh
pnpm install
pnpm dev
```

## Verificación

```sh
pnpm test
pnpm build
```

El despliegue se configura de forma independiente según el entorno de publicación elegido.

La publicación del vídeo y el apartado «Día de la lucha contra la pobreza», junto con el procedimiento para incorporar futuras actividades, se documenta en [docs/poverty-day-2026.md](docs/poverty-day-2026.md).
